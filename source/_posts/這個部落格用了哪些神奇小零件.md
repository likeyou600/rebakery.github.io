## 實用類的

### Giscus
[🍊Giscus](https://giscus.app/zh-TW)
文章留言板，誰會當第一個留言者呢

### 流量追蹤
[🎂cloudflare](https://www.cloudflare.com/zh-tw/)

[🌽goatcounter](https://www.goatcounter.com/)

所以如果你正在看這篇文章，  
代表這裡的數字可能又 +1 了 :>

### Sitemap
[🗺️Sitemap](https://github.com/hexojs/hexo-generator-sitemap)
幫搜尋引擎整理網站有哪些頁面，
可以丟給 Google Search Console 用。

網址 : https://rebakery.net/sitemap.xml

### GitHub Actions 自動部署
寫文章 -> git push -> 發 Release -> GitHub Actions build -> GitHub Pages 更新

可以參考 [deploy.yml](這個部落格用了哪些神奇小零件/deploy.yml)
