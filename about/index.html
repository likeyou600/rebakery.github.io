關於我與這個網站

關於我

安安，誤入這個部落格的人。我是 Bakery，大學和研究所都念資訊工程，卻不務正業地接起了網頁案子。
2022 年初，在 AI 還沒有搶佔我飯碗的時候，開啟了在PTT、小雞上工、學校教授之間的接案之路。
結果一直到 2026 年才開了一個部落格。不過 Codex 很厲害，不到一天就弄好了🍵

如果文章裡有寫錯的地方，也請多多留言指教。

關於這個網站

目前希望先把之前做過的一些網站作品整理上來，

研究所期間，也開始接觸了一些韌體相關的東西，
之後也會放一些韌體小 project，還有一些生活或開發途中遇到的小紀錄。

從 ChatGPT 到 Coding Agent

2025 年，能處理整個專案的 coding agent 開始崛起。
那時我正水深火熱寫論文，對 AI 的理解還停留在 ChatGPT 是這種拿來對話、查資料、整理文字的工具。與其說是不相信，不如說是這個領域變化太快，快到讓人有點不想面對。

畢業後沒多久，又緊接著進入封閉的當兵世界。對於當時假日的我來說，只想要休息耍廢。
還記得下部隊時，Gemini 3 發布了。Threads、FB、IG 上，每個人、每篇文章都在分享自己用 AI 做出來的小 project。
那時覺得徹底天崩了，很恐慌，我卻躺在軍營床上(的確過太爽)。

當兵後持續逃避，直到面試題目開始出現，你有沒有用 AI Coding 相關經驗 ?_?
目前只希望慢慢補起來 : )
